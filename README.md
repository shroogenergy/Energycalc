# Energy Project Screening Studio

A lightweight energy-consulting decision tool for first-pass renewable project screening.

## What it does

- Calculates unlevered NPV and project IRR
- Estimates discounted LCOE
- Estimates simple payback period
- Converts outputs into a GO / HOLD / NO-GO recommendation
- Flags weak economics and sensitive assumptions
- Includes a Saudi solar PV base case and a one-click stress case

## Purpose

Built as a portfolio project to demonstrate energy project economics, structured decision-making, and consulting-style synthesis. It is a screening model, not a bankable financial model or investment recommendation.
